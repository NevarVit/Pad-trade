# Tradepad для FydeOS

Компактная 18-клавишная раскладка ZMK для `nice_nano_v2`, оптимизированная под **FydeOS** (ChromeOS).

> **Философия:** минимум клавиш — максимум возможностей.  
> Четыре слоя, шесть комбо, встроенные горячие клавиши FydeOS.

---

## 🗺️ Слои

### Слой 0 — Default
Базовый слой. Цифры, буфер обмена, модификаторы, выход на слои 1 и 2.

|  |  |  |  |  |  |
|---|---|---|---|---|---|
| `Tab` | `1` | `2` | `4` | `8` | `Bspc` |
| `Shift` | `Ctrl+C` | `Ctrl+X` | `Ctrl+Z` | `Ctrl+V` | `Del` |
| `Ctrl` | `Alt` | — | `Space` | `&mo 2` | `&mo 1` |

### Слой 1 — Work
Навигация, стрелки и быстрый доступ к букве `E`.

|  |  |  |  |  |  |
|---|---|---|---|---|---|
| `Esc` | `↑` | — | — | `Home` | `PgUp` |
| `←` | `↓` | `→` | `E` | `End` | `PgDn` |
| — | — | — | — | — | — |

### Слой 2 — Function
Функциональные клавиши и системные shortcuts FydeOS.

|  |  |  |  |  |  |
|---|---|---|---|---|---|
| `F1` | `F2` | `F3` | `F4` | `F5` | `F6` |
| `F7` | `F8` | `F9` | `F10` | `F11` | `F12` |
| `🌙 Sleep` | `⛶ Fullscreen` | — | `📸 Full screenshot` | — | `&mo 3` |

### Слой 3 — Special
Служебный слой. Скриншот области и `Bootloader` для прошивки.

|  |  |  |  |  |  |
|---|---|---|---|---|---|
| — | — | — | — | — | `Bootloader` |
| — | — | — | — | — | — |
| — | — | — | `📷 Area screenshot` | — | — |

## 🎯 Комбо

Цифры собраны по принципу **двоичного сложения** — каждая клавиша верхнего ряда представляет степень двойки.

| Комбо | Клавиши | Результат |
|---|---|---|
| `1 + 2` | `1` `2` | **3** |
| `1 + 4` | `1` `4` | **5** |
| `2 + 4` | `2` `4` | **6** |
| `1 + 2 + 4` | `1` `2` `4` | **7** |
| `1 + 8` | `1` `8` | **9** |
| `2 + 8` | `2` `8` | **0** |

> Комбо работают только на слое **Default**.

## 🖥️ Горячие клавиши FydeOS

На слоях **Function** и **Special** собраны системные сочетания, протестированные на FydeOS:

| Клавиша | Действие | Комбинация FydeOS |
|---|---|---|
| `Fn + R3C1` | 🌙 **Сон** | `Shift + Search + L` |
| `Fn + R3C2` | ⛶ **Полный экран** | `Search + F4` |
| `Fn + R3C4` | 📸 **Скриншот всего экрана** | `Ctrl + F5` |
| `Sp + R3C4` | 📷 **Скриншот области** | `Shift + Ctrl + F5` |

> **Search (❖)** — клавиша `Left GUI` в ZMK.  
> Комбинация сна проверена и работает на FydeOS for PC.

---

## ⚙️ Настройка FydeOS

Перед использованием слоя **Function** убедитесь, что в системе включён режим функциональных клавиш:

**Настройки → Устройства → Клавиатура → «Использовать функциональные клавиши как клавиши верхнего ряда»**

Без этой опции клавиши `F1`–`F12` отправляются как медиа-команды (яркость, громкость),
и сочетания `Ctrl + F5` / `Shift + Ctrl + F5` не срабатывают.

## 🔧 Установка

```bash
west build -s zmk/app -b nice_nano_v2 -- \
  -DZMK_CONFIG=/path/to/config \
  -DSHIELD=tradepad
```

Прошивка появится в `build/zephyr/zmk.uf2`.

## 📝 Заметки

- **Mod-tap** не используется — все модификаторы явные.
- **Combos** активны только на слое 0, чтобы не конфликтовать с навигацией.
- **Bootloader** вынесен на слой 3 и доступен через удержание `&mo 3` на слое Function.
- **Скриншоты** работают только при включённой опции «функциональные клавиши как верхний ряд».
